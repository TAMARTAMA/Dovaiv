# Dovaiv — AI-Powered Torah Learning

[**Explore the live product →**](https://www.dovaiv.com/)

Dovaiv is a production web experience for learning Torah through AI-powered conversations with *RabbAIs* — distinct learning personas inspired by timeless rabbinic voices. Users can ask a question, learn one-on-one, compare perspectives in a multi-participant discussion, and explore questions by topic.

> This repository is a public portfolio case study. It intentionally contains no proprietary production code, private data, or credentials.

## My role

**Full Stack Developer · Koren Digital**

I contributed to building and evolving the production experience, with a focus on translating a complex AI-learning concept into a clear, approachable web product. My work involved the user-facing learning flows, responsive product UI, and the interactions that guide a learner from a question to a focused learning experience.

## Product highlights

- **RabbAI selection and question flow** — choose a learning persona and begin with a question.
- **Two learning modes** — one-on-one learning with a single RabbAI or a discussion between multiple RabbAIs.
- **Perspective-driven discussions** — suggested pairings make contrasting approaches easy to explore.
- **Topic discovery** — entry points for Halacha, Torah study, faith, and other learning themes.
- **Bilingual experience** — English and Hebrew interface support.
- **Responsible AI context** — clear educational-use disclaimer for halachic and life decisions.

## What this project demonstrates
